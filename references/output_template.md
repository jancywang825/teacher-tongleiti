## 自检清单（生成后必过）
- [ ] 原创题知识点与原题标签一致？
- [ ] 原创题主方法与原题方法标签一致（未偷换方法）？
- [ ] **未做纯数字替换**（采用了 ≥2 类结构性原创改动：情境重构/结构反转/知识嫁接/图形变换）？
- [ ] **子问参数链完整**：遮住 (1) 的答案，(2)(3) 无法独立求解（题面保留含参表达式，未把代入化简的数字形式写进题面）？
- [ ] **结构同构**：二次项/一次项/常数项的参数构成方式与母题一致（如 `amx^2+(m-a)x-1` 仍写成含 a、m 的组合）？
- [ ] **公式全 LaTeX 化**：题干/选项/答案/解析中无纯文本或 Unicode 上标公式（如 `x^2`→`$x^2$`，`amx²`→`$amx^2$`）？
- [ ] **主交付物为 .docx**：LaTeX 公式已转 Word 原生公式（OMML），在 Word/WPS 中直接显示为排版公式；`.md` 仅作可选源文件？
- [ ] **知识点与解法不超纲（回溯双检）**：全部知识点与解法限定在母题学段课标内——通用禁积分符号（∫）、微分方程解析解（cosh 等）、双曲函数、数密度/质量流率大学定义式；**有机专项须过白名单/黑名单回溯双检**：逐知识点回验能否由课标或题面已知推出，禁用格氏试剂/有机锂、酰氯/SOCl₂、分子重排、开放式逆合成、人名反应、SN1/SN2 机理、保护基、超课标金属催化；含黑名单内容已改写为白名单等价路径或降级为纯信息填空；信息给予已给具体反应式且能机械迁移；题干每个符号都在题内定义？
- [ ] **Word 公式不乱码**：OMML 公式内无 CJK 字符（中文下标改拉丁下标、中文含义移正文）、无 "frac"/"times" 等命令残留字面；构建后已程序校验（遍历 oMath 文本节点）？
