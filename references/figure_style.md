# 配图绘制风格规范（matplotlib 实现细则）

> 2026-10-13 用户确立的硬约束。所有条件图（2D 函数图 / 3D 立体几何图）一律遵守。
> 参照实现：`图形脚本/条件图生成.py`（2D）、`图形脚本/四棱锥5题配图.py`（3D，含遮挡判定）。

## 1. 颜色统一黑色

- 定义单一墨色常量：`INK = "#111111"`，全部元素复用，禁止蓝（`#1f4e79`/`#2b6cb0`）、红（`#c0392b`/`#c53030`）、灰（`#444`/`#555`/`#bbbbbb`）等彩色。
- 适用元素：曲线、棱、坐标轴与箭头、刻度短线、散点、顶点名、长度标注、直角标记。
- **辅助线保持虚线但改黑色**：2D 函数图的水平/竖直辅助线 `ls="--", color=INK`；3D 隐藏棱 `ls=(0,(4,3)), color=INK`。

## 2. 坐标点偏小

| 场景 | 参数 | 取值 |
|---|---|---|
| 2D 曲线上的点（`ax.plot(...,"o")`） | `ms` | `3.5`（原 6 偏大） |
| 3D 顶点散点（`ax.scatter`） | `s` | `14`（原 34/45 偏大） |

点仍须可见、可辨认，但不得喧宾夺主。

## 3. 立体几何"背后线"用虚线（凸多面体面朝向法）

**判定规则**：对每条棱，找出它的两个相邻面；计算每个面的**外法线**（法线方向取背离多面体重心一侧）：

- 两个相邻面均背向相机（`n·d ≤ 0`）⇒ **背后棱 → 虚线**
- 一背一朝 ⇒ 轮廓棱 → 实线
- 两面均朝向相机 ⇒ 可见棱 → 实线

其中视线方向（由 `view_init(azim, elev)` 得）：
`d = (cos(elev)cos(azim), cos(elev)sin(azim), sin(elev))`

**代码要点**（完整实现见 `图形脚本/四棱锥5题配图.py` 的 `hidden_edges()`）：

```python
def hidden_edges(points, edges, faces, azim, elev):
    d = cam_dir(azim, elev)          # 视线方向（指向相机）
    centroid = mean(所有顶点)
    hidden = set()
    for (a,b) in edges:
        adj = [f for f in faces if a in f and b in f]   # 棱的相邻面
        back = 0
        for f in adj:
            n = 面法线(f)                        # 叉积
            if n · (面中心 - centroid) < 0: n = -n   # 统一为外法线
            if n · d <= 0: back += 1
        if back == len(adj):                    # 两面均背向 ⇒ 隐藏
            hidden.add((a,b))
    return hidden
```

**faces 构造**（锥体约定）：`points` 字典前 4 个键为底面顶点（按环绕顺序）、最后为顶点 `'P'`；
`faces = [底面四边形] + [[P, base[i], base[i+1]] for i in range(4)]`。

**渲染**：虚线 `ls=(0,(4,3)), lw≈1.8`；实线 `lw≈1.8`；全部 `color=INK`。

**自检**：脚本运行时打印每图被判为背后的棱集合（如 `[('A','B'),('D','A'),('P','A')]`——即"后角"顶点相连的三条棱），出图后目检确认虚线确实落在远侧、实线在近侧。

## 4. 点/线标签"贴着但不重叠"（2026-10-13 用户新增）

**原则**：标签要紧挨着它标注的点/线（一眼能看出标的是谁），但绝不能压在点或线上。

**3D 立体几何图**（参照 `图形脚本/四棱锥5题配图.py`）：

- **顶点标签**：沿"该点相对全体顶点质心的朝外方向"偏移后放置——
  `d = p - centroid; d = d/‖d‖ * 0.22`，文本锚点 = `p + d`，`ha='left', va='center'`。
  效果：底面顶点标签向外推（不会伸进图形内部），顶点 P 标签向上推。
- **长度/棱标注**：放在**棱中点沿棱法向**偏移处并朝图形外侧——
  `perp = (-dy, dx, 0)`（棱方向 `(dx,dy,dz)` 的 xy 面法向），单位化 ×0.25；
  若 `perp·(mid - centroid) < 0` 则取反向（推向图形外侧）；
  竖直棱（dx=dy≈0）法向无定义，回退为固定 `(0.25, 0, 0)`。
- **禁止**：标签锚点直接取点坐标或线段中点（`ax.text(x,y,z,...)` 不加偏移）。

**2D 函数图**（参照 `图形脚本/条件图生成.py`，已天然合规）：

- 横轴刻度/零点标签：放在轴**下方**（`y = -0.17*A, va='top'`），与 x 轴留细缝；
- 纵轴刻度/水平线标签：放在轴/线**左侧**（`ha='right'`）；
- 轴名贴横轴箭头末端右侧、纵轴名贴箭头上方，紧贴但不压轴线。

**交付前目检新增项**：逐一确认每个点标签不压点、每个长度/刻度标签不压线，且间距 ≤ 一个字符宽（贴着）。
