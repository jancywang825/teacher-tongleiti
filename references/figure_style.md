# 配图绘制风格规范（matplotlib 实现细则）

> 2026-10-13 用户确立的硬约束。所有条件图（2D 函数图 / 3D 立体几何图）一律遵守。
> 参照实现：`图形脚本/条件图生成.py`（2D）、`图形脚本/四棱锥5题配图.py`（3D，含遮挡判定）。
> 顶点标签避线共用模块随 skill 附带：`scripts/geo_label.py`（项目内副本：`图形脚本/geo_label.py`）。

## 1. 颜色统一黑色

- 定义单一墨色常量：`INK = "#111111"`，全部元素复用，禁止蓝（`#1f4e79`/`#2b6cb0`）、红（`#c0392b`/`#c53030`）、灰（`#444`/`#555`/`#bbbbbb`）等彩色。
- 适用元素：曲线、棱、坐标轴与箭头、刻度短线、散点、顶点名、直角标记（几何图不标线段长度，长度只在题干文字给出）。
- **辅助线保持虚线但改黑色**：2D 函数图的水平/竖直辅助线 `ls="--", color=INK`；3D 隐藏棱 `ls=(0,(4,3)), color=INK`。

## 2. 坐标点偏小

| 场景 | 参数 | 取值 |
|---|---|---|
| 2D 曲线上的点（`ax.plot(...,"o")`） | `ms` | `3.5`（原 6 偏大） |
| 3D 顶点散点（`ax.scatter`） | `s` | `9`（更小更细，仅作小黑点） |

点仍须可见、可辨认，但不得喧宾夺主。

**线宽统一更细**：3D 棱线 `lw≈1.2`（原 1.8 偏粗），2D 函数曲线 `lw≈1.3`；直角标记等辅助线相应减细。

**几何图形只标顶点、不标线段长度（2026-10-14 用户新增）**：条件图【不在图形上标注线段长度】，只标基础顶点字母（A/B/C/D/P…）。已知长度统一写在题干文字中。顶点小黑点更小（`s≈9`）、棱线更细（`lw≈1.2`）；顶点字母置于顶点旁（沿"顶点相对全体顶点质心朝外方向"小幅偏移，如 `d/‖d‖*0.24`，或按顶点定制偏移），确保字母**不压在任何棱线上**（落在图形外侧）。2D 几何图同理：只标顶点字母、不标边长，点更小线更细。

## 3. 立体几何"背后线"用虚线（凸多面体面朝向法）

**判定规则**：对每条棱，找出它的两个相邻面；计算每个面的**外法线**（法线方向取背离多面体重心一侧）：

- 两个相邻面均背向相机（`n·d ≤ 0`）⇒ **背后棱 → 虚线**
- 一背一朝 ⇒ 轮廓棱 → 实线
- 两面均朝向相机 ⇒ 可见棱 → 实线

其中视线方向（由 `view_init(azim, elev)` 得）：
`d = (cos(elev)cos(azim), cos(elev)sin(azim), sin(elev))`

**代码要点**（完整实现见 `图形脚本/四棱锥5题配图.py` 的 `hidden_edges()`）：

```python
def hidden_edges(points, edges, faces, azim, elev):
    d = cam_dir(azim, elev)          # 视线方向（指向相机）
    centroid = mean(所有顶点)
    hidden = set()
    for (a,b) in edges:
        adj = [f for f in faces if a in f and b in f]   # 棱的相邻面
        back = 0
        for f in adj:
            n = 面法线(f)                        # 叉积
            if n · (面中心 - centroid) < 0: n = -n   # 统一为外法线
            if n · d <= 0: back += 1
        if back == len(adj):                    # 两面均背向 ⇒ 隐藏
            hidden.add((a,b))
    return hidden
```

**faces 构造**（锥体约定）：`points` 字典前 4 个键为底面顶点（按环绕顺序）、最后为顶点 `'P'`；
`faces = [底面四边形] + [[P, base[i], base[i+1]] for i in range(4)]`。

**渲染**：虚线 `ls=(0,(4,3)), lw≈1.8`；实线 `lw≈1.8`；全部 `color=INK`。

**自检**：脚本运行时打印每图被判为背后的棱集合（如 `[('A','B'),('D','A'),('P','A')]`——即"后角"顶点相连的三条棱），出图后目检确认虚线确实落在远侧、实线在近侧。

## 4. 点/线标签"贴着但不重叠"（2026-10-13 用户新增）

**原则**：标签要紧挨着它标注的点/线（一眼能看出标的是谁），但绝不能压在点或线上。

**3D 立体几何图**（参照 `图形脚本/四棱锥5题配图.py`）：

- **顶点标签（屏幕空间避线自动放置，2026-10-14 升级）**：用共用模块
  `图形脚本/geo_label.py` 的 `place_labels(ax, points, edges)`——把顶点与**所有**棱
  投影到屏幕 2D 平面，初始方向取"该顶点所有邻边单位向量的反向和"（角的外侧），
  再按 ±15° 步进旋转搜索，直到标签中心到**所有**棱线段的 2D 距离 ≥ `line_pad`(0.16)，
  把选中方向映射回 3D 放置（`ha/va='center'`）。效果：字母贴着顶点旁，**绝不压线**
  （含背后虚线棱，以及点所落的线，如 E∈AD、F 为 PE 中点）。
- **长度/棱标注（3D 几何图已取消）**：3D 几何条件图**不再标注线段长度**
  （见第 2 节"几何图形只标顶点、不标线段长度"），已知长度一律写在题干文字中。
  2D 函数图如需沿线标注，放在**线中点沿法向**偏移处并朝图形外侧——
  `perp = (-dy, dx)`，单位化 ×0.25；若 `perp·(mid - centroid) < 0` 则取反向；
  竖直线（dx=dy≈0）法向无定义时回退固定 `(0.25, 0)`。
- **禁止**：标签锚点直接取点坐标或线段中点（`ax.text(x,y,z,...)` 不加偏移）。

**2D 函数图**（参照 `图形脚本/条件图生成.py`，已天然合规）：

- 横轴刻度/零点标签：放在轴**下方**（`y = -0.17*A, va='top'`），与 x 轴留细缝；
- 纵轴刻度/水平线标签：放在轴/线**左侧**（`ha='right'`）；
- 轴名贴横轴箭头末端右侧、纵轴名贴箭头上方，紧贴但不压轴线。

**交付前目检新增项**：逐一确认每个点标签不压点、每个长度/刻度标签不压线，且间距 ≤ 一个字符宽（贴着）。

## 6. 物理 / 化学实景装置图具象化（ImageGen 写实渲染，2026-10-16 新增）

数学的几何 / 函数 / 坐标图维持第 1~5 节的全黑矢量规范（精度与可编辑优先）。物理 / 化学的**实景装置图、生活情境图**（酒精灯、铁架台、烧杯、试管、量筒、天平、SUV、叉车、扫地机器人、灶锅、蒸锅、高压锅等）必须**具象、逼真、一眼可辨实体**，禁止骨架式纯线稿剪影。

**实现方式（首选 ImageGen 写实 / 精细插画）**：
- 提示词须明确实体名称、视角、比例，例如「white background, realistic illustration of a chemistry lab setup: an iron stand holding a beaker on a wire gauze over an alcohol burner, a thermometer inserted into the beaker with its bulb near the bottom, no text, no numbers, no labels」。
- 强制「no text, no numbers, no labels」，避免 AI 生成错乱字符；同时「仅含题设条件元素，不出现答案 / 推导结论」（如不标温度读数、不画暗示结论的气泡特写）。
- 交付高分辨率 PNG + **记录可复现的 ImageGen 提示词**（用户可据提示词重新生成 / 调整）；该情形下**放宽**「全黑线条 / SVG 可编辑 / 参数化脚本」要求，不强制 SVG / 参数化脚本。

**仅在无法使用 ImageGen 时**退化为 matplotlib 精细线稿：加入透视 / 明暗 / 组件细节（玻璃器皿双层壁与高光、温度计刻度与玻璃泡、酒精灯灯帽与火焰、车轮与车身轮廓、叉车货叉等），避免抽象骨架线稿。

**自检新增项**：一眼能否认出图中实体？若仍像抽象符号 / 骨架线，须重画或改用 ImageGen。
